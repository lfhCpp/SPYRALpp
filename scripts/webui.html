这是什么

AT-TPC 的模拟 + 重建 C++ 实现（librk4.so + 5 个命令行程序）。 这个页面把流程包成按钮：改参数 → 生成配置 → 跑波形/重建 → 看日志和产物。

流程与 Python 版 Spyral 一致： 原始波形 → 点云 → 聚类 → 粗估 → 拟合。中间文件可选用 「输出 → stages / dump」打开。

三步上手

  1. 在 参数 页填 run.input（原始 .h5）或 run.clouds（已有想点云）， 设 run.n_events 先跑小批量（例如 200）。
  2. 去 运行 页点 生成点云，看日志里「波形转换完成… 输出 N 个点云」。
  3. 点 重建（同一页），完成后到 产物 页确认 web_fit.root。

想调物理结果，按这个顺序动参数：

  • B 场符号：真实数据手性不对时一条都拟不上 → 试 detector.bfield_t = -2.85。
  • 峰的定法：peaks.template_fit 0 = 局部极大（快）；1 = 电子学响应模板拟合（含饱和修复、重叠峰拆分）。
  • 聚类：首要 cluster.eps_mm、cluster.min_points、cluster.min_cluster_size； 稀疏真实数据先试 eps_mm=30~40、min_cluster_size=5。
  • 拟合后端：solver.fitter = minuit（稳、慢、不随线程加速）或 kalman（快一个量级、能并行，真实数据要把 kalman_meas_sigma 调到 ~5 mm）。
  • PID 预筛：pid.gate=1 + pid.min_sep，在拟合前挡掉不像目标粒子的簇。

命令行等价写法

页面做的事就是下面这些，配置都写在 web_output/web.cfg，可以直接拿去命令行复现：

build/rk4_waveform web_output/web.cfg <input.h5> web_output/web_cloud.root 200 8
SPYRALPP_THREADS=8 build/rk4_analyze web_output/web_cloud.root web_output/web_fit.root web_output/web.cfg
scripts/spyralpp web_output/web.cfg --input <input.h5> --events 200 --threads 8   # 一条命令版
